# 12-30-tilda-ui

UI-компоненты и страницы для сайта ресейл-проекта **12:30** на Tilda.

Чистые HTML / CSS / JS, без фреймворков. Каждый компонент — самостоятельный файл для вставки в HTML-блок Tilda **T123**.

## Структура

```
components/
  <component-name>/
    index.html   # HTML + CSS + JS компонента
```

## Как вставить компонент в Tilda

1. Открыть `components/<component-name>/index.html` и скопировать всё содержимое.
2. В редакторе Tilda добавить блок **T123** («Другое» → «HTML-код»).
3. Вставить код, сохранить и опубликовать страницу.

Чтобы удалить компонент — удалить соответствующий блок T123.

## Соглашения

- Все CSS-классы с префиксом `s1230-`.
- Глобальные стили Tilda не переопределяются.
- Desktop и mobile обязательны.

Подробные правила — в [CLAUDE.md](CLAUDE.md).
